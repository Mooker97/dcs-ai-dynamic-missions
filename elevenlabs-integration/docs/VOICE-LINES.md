# Generic Voice Lines

**Recording Status Legend:**
- ✅ = Audio file exists
- ⏳ = Planned/needs recording

## Additional Categories to Consider

- **CSAR / Extraction** - Rescue coordination lines
- **BDA (Battle Damage Assessment)** - Post-strike assessments
- **Reconnaissance Reports** - Intel callouts
- **Status Updates** - Progress reports during ops
- **Egress / RTB** - Return to base coordination
- **Target Marking** - Laser/smoke marking callouts
- **Casualties** - Friendly unit status
- **Reinforcements** - Additional units arriving

---

## File Organization

Audio files should be organized in the following structure within the .miz file's `l10n/DEFAULT/` folder:

```
audio/
  generic/
    ground-troops/
      requesting-support/
      good-strike/
      keep-going/
      taking-fire/
      target-spotted/
      negative-results/
      winchester-bingo/
      friendly-fire-warning/
    mission/
      mission-start/
      mission-complete/
      abort-waveoff/
    threats/
      sam-warning/
      enemy-aircraft/
      weather-visibility/
  missions/
    [mission-specific-name]/
      (custom voice lines for specific missions)
```

---

## Usage in DMS.Audio

```lua
-- Register voice line libraries
DMS.Audio.registerLibrary("ground_support", {
  need_support = "generic/ground-troops/requesting-support/we-need-air-support-now.wav",
  good_kill = "generic/ground-troops/good-strike/good-kill-good-kill.wav",
  keep_going = "generic/ground-troops/keep-going/good-hit-keep-it-coming.wav",
  -- etc...
})

-- Play random line from category
DMS.Audio.playRandomFromLibrary("ground_support")

-- Play specific line
DMS.Audio.playFromLibrary("ground_support", "good_kill")
```
