## 📝 Usage Guide

### How to Use These Prompts:

1. **Go to ElevenLabs Voice Lab:**
   https://elevenlabs.io/app/voice-lab

2. **Click "Add Voice" → "Voice Design"**

3. **Copy a prompt** from above

4. **Paste into description field**

5. **Click "Generate"**

6. **Test with sample phrases:**
   - "We need air support, NOW!"
   - "Mission is a go. Good hunting."
   - "Target destroyed. Good kill."

7. **If satisfied:**
   - Click "Save Voice"
   - Give it a name (use callsign from headers)
   - Copy Voice ID

8. **Update voice_config.json** with new voice
