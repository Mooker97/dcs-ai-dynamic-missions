# Premise

Plugin smoke test bed (docs/rebuild/PLAN.md A6), not a story campaign. It reuses the Viper
Detachment bible and its first two missions to prove the optional plugins (ADR 0003/0013) in a
headless DCS run: p01-skynet (Skynet-IADS + the DMS adapter) and p02-moose (MOOSE). Subtitles only;
no ElevenLabs voice is needed to build either mission.
