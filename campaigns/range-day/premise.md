# Premise

## Pitch

PYTHON 1-1 is an F-16C pilot back on flying status after a long ground tour, and has to fly a
laser-guided bomb requalification on Range Seven, south of Incirlik, before Rook detachment will
schedule them for combat sorties again. The range controller, Anvil, talks the switches through
step by step. The pilot also sits alert for close air support with the last two bombs, and the
alert comes up on the radio before the range card is signed.

The mission is a refresher by design: the radio coaching and the kneeboard cheat sheet teach the
F-16 laser-guided bomb sequence (master arm, laser arm, A-G mode, SMS, TGP, TMS, laser, pickle)
again to a pilot who hasn't flown in a long time.

| Realism (grounded / stylised / fantasy) | grounded |
| Mode (historical / adapted / fictional) | fictional: invented range, unit, tasking and calendar; real terrain only |
| Player aircraft and callsign | F-16C_50, single ship, PYTHON 1-1 (user: "f16") |
| Theater / home base | Syria map, Incirlik (user: "syria") |
| Start | hot start on the ramp only (user: "ramp start hot"); no air start variant |
| Weapons | laser-guided bombs, self-lased with the targeting pod (user: "lazer bombing"); preset lgb_strike, 4x GBU-12 |
| Training range | yes (user: "training range"): two range passes with coaching, then a live tasking |
| Voice | full voice (user: "full voice"); cost cap assumed about 3 USD, since a w02-sized mission was about 1 USD |
| Scope (missions, session length) | 1 standalone mission, about 60-70 min |
| Failure tolerance | fail forward; timeouts move the mission on, no dead ends |
| Hard no's | none stated; keep threats light, because this is a refresher |
| Test | headless DCS run with an AI proxy before hand-over (user request) |

## Inspirations

- A real USAF range requalification ride: an RCO clears each pass and calls the hits.
- Rook detachment, Incirlik and the Tell Rifaat plain reuse the setting of the viper-detachment
  campaign as terrain and flavour only. This campaign is standalone.
