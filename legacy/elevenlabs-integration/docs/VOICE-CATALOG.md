## Usage

### Create Voice
1. Go to https://elevenlabs.io/app/voice-lab
2. Click "Add Voice" → "Voice Design"
3. Copy prompt from above
4. Paste and generate
5. Save voice and copy Voice ID

### Generate Voice Lines
```bash
cd elevenlabs-integration/scripts
python generate_with_custom_voices.py
```

Configure voices in: `config/voice_config.json`
